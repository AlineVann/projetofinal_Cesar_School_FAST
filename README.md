# Sobre o Projeto
Projeto final desenvolvido durante o FAST (Formação Acelerada em Soluções TechDesign) da CESAR School, na trilha de Design Orientado a Dados.

O desafio foi criar uma solução digital para mitigar a falta de acompanhamento em pacientes pós-cirúrgicos, utilizando dados para aumentar o engajamento e prevenir complicações.

# 📊 Abordagem Data-Driven (Design Orientado a Dados)
Como parte da metodologia do curso, o design foi guiado por decisões baseadas em dados e métricas de sucesso:

O Problema (Dados de Pesquisa):Identificamos que uma quantidade grande de pacientes abandonam a fisioterapia por falta de orientação imediata (insira um dado real ou fictício do seu pitch se tiver).
 Métricas de Sucesso (KPIs Propostos):
 Taxa de Retenção:* Frequência diária de login no app.
 NPS (Net Promoter Score): Satisfação do paciente com a recuperação.
 Redução de Reincidência: Comparativo de retorno hospitalar entre usuários vs. não usuários.
 Coleta de Dados no App: O protótipo inclui funcionalidades de "Diário de Dor" e "Monitoramento de Humor" para gerar insights médicos em tempo real.

 Ferramentas e Metodologia
Figma & FigJam: Prototipação, Fluxo de Usuário e Pitch Deck.
Metodologia: Design Thinking com foco em Analytics e UX Data Driven.
Instituição: CESAR School (Programa FAST).

 Funcionalidades da Solução
1.  Dashboard de Evolução: Visualização de dados para o paciente acompanhar seu progresso.
2.  Alertas Inteligentes: Notificações baseadas nos dados inseridos (ex: "Sua dor aumentou 20% hoje, contate o médico").
3.  Gamificação Baseada em Metas: Recompensas por constância no tratamento.
